.study-note: A div that contains each Bible study. Each study can contain multiple translations of the same verse.
.bible-quote: The container for each translation of the verse. It includes different versions of the Bible like NIV, ESV, KJV, etc.
.niv, .esv, .nkjv, .kjv, .csb, .nasb, .ceb: Classes for different Bible translations. These are used to display different versions of a verse.
.active: A class used to show the currently active translation. The translations that are active will be displayed on the screen.
.tab: The container for the translation tab at the bottom of the screen. This tab lets users swipe left or right to switch translations.
